# PTA-Doubao-Windows

基于 Python 和 Playwright 的 Windows 网页自动化练习工具。

## 项目介绍

本项目用于探索 PTA 编程练习平台与豆包网页之间的浏览器自动化流程，包括题目读取、C 语言代码生成、编辑器填写及本地检查等。

**仅限平台规则允许 AI 辅助和自动化操作的场景使用。**

## 主要功能

- Windows BAT 一键启动
- 自动检测 Windows Python
- 自动安装 Playwright 依赖
- 支持 C11 代码编译检查
- 支持部分样例测试
- 运行异常时保存诊断日志

## 安装和使用

1. 打开 GitHub 项目的 **Releases** 页面。
2. 下载最新版本的 ZIP 安装包。
3. 将 ZIP 完整解压到本地文件夹。
4. 双击 `START_PTA_Doubao.bat`。
5. 根据提示完成环境准备。
6. 在允许使用自动化的练习环境中测试。

首次运行需要联网。部分验证功能需要 GCC 或 Clang 编译器。

## 运行环境

- Windows 10 / Windows 11
- Python 3.12
- Chrome、Edge 或 Playwright Chromium
- Playwright
- GCC / Clang（用于严格编译验证）

## 注意事项

- 本项目不保证所有题目通过，也不保证正确率达到 95%。
- PTA 隐藏测试可能发现样例测试未覆盖的问题。
- 自动安装、浏览器兼容性和网页结构变化可能影响运行。
- 不要上传浏览器登录资料、个人日志或账号凭据。
- 请遵守 PTA、豆包及所在学校的使用规定。
